# 小说积木

把一部长篇拆成模块，每个模块由大量小块（积木）组成，**一块一个文件**。

**先找到项目目录**——它里面应该有 `骨架/线索引.md`。
找不到就问作者；要开新项目就用 `scripts/init-project.mjs`。

## 铁律

前五条最容易被违反，动笔前逐条过一遍。

1. **骨架是一条写作顺序的直线。** B01、B02、B03……一路往下。
   线（视角）只是块上的一个字段，换线＝换一双眼睛。
   **不许摆并行泳道**，不许把同时发生的事排成两条并排轨道——那样下一块该写哪里就分不清了。
2. **新角色必须先立卡才能入戏。** 正式角色六块必填：名字、定位、来历、能力或手段、底线、当前目标，
   缺一块不算完成创建。无名角色五块以内、登记不立卡；一旦第二次出现或被点名，必须升级为正式角色。
3. **线索一出生就得有落点。** 入、出，以及出口块前后各一块，必须同时存在；
   有入无出就是问题（状态标「废弃」的除外）。落点很远就给它打 `🕳远端`。
4. **改写不得落在已写完的正文里。** 因果链接改的是角色卡或关系线，撞上已写区域时**停下来问作者**，
   不要默默改——否则已经写出来的字和检查器的判断会对不上。
5. **延伸骨架时冒出的东西立刻分流**：新角色→待立卡队列；新地点→待建场景队列；
   关系变化→关系变更队列；线索→线索模块。分流完再继续规划。
6. 正文一律 `.txt`；设定、骨架、台账一律 `.md`，**一块一个文件**。
   **正文写进一份连续文本，不要按章拆文件**——划章是作者的事，切成「第N章」就等于替作者划了。
7. 表格列序固定，**空白列要留 `| |`**——列是按位置读的，省掉就串位：
   `| 块 | 线 | 简述 | 时间 | 时间位 | 预估 | 标签 | 状态 |`
8. **＋20k**：写作位置**之后**的块，预估字数累计 ≥ 20000，才允许动笔。只能多，不能少。
9. **写完一块当场核两样**：情绪对不对、字数落在预估的 **0.8–1.2 倍**之间。
   不够就补**场景细节**，不是补形容词。
10. **先定情绪，再写句子。**每块先问「这场戏里谁在什么情绪」，句法和标点从那里长出来——
    **可测口径表只用于事后自查，是警报器不是方向盘**。为了凑标点去改人物的反应，就是填表。
11. **每个有名字的角色必须有一份口吻卡**（`文风/人物口吻.md`），写他的对白前先读。
    没有卡的角色一律当**无名角色**：不给名字、不给口癖、不给第二场戏。
    凶靠反问不靠字少；自信除了盯着人看，还可以写得轻浮一点。
12. **顺序不能反**：表的数字只有在"情绪—句子"这条路走完以后才有意义。

## 循环

1. **骨架生成**——重头戏。排块、连线、算节奏分；多方面因素、信息的交流与修改、
   连贯性与合理性都在这一步。
2. **血肉填充**——几乎单向：照骨架写 → 检查 → 修改。写到哪停由作者发指令（如「继续写 3000 字左右」）。
3. **回退**——写不通就回头改骨架，这是唯一反向的路。改完查影响面：
   挂在这块上的线索入出、角色改写、关系变更要不要跟着动。

没有独立的「书写模块」，书写就是照骨架写。

**节奏分决定字数**：`重要性×2 ＋ 前后联系×1 ＋ 情绪强度×1`，4–20 分映射到 10–1000 字。
权重和分档都是暂定的，作者要调就调。

## 检查

填完一段血肉就跑一遍；自然收束点跑深检查；作者点名跑触发式。
每个检查器只读自己那几块，报警必须带块号、依据、建议三样。

**检查器的有效性上限＝台账的完整度**——它只能发现「和记录冲突」，发现不了「记录里根本没写」。
查不出问题不等于内容没问题。

## 目录

```text
《项目名》/
  骨架/     线索引.md、写作顺序.md、块/B01_*.md
  角色/     <名字>/{卡.md, 积木/, 认知边界.md, 变更/}
  场景/     地点索引.md、<地点>.md
  关系/     <A>_对_<B>.md     A对B与B对A分开
  线索/     C01_*.md
  世界观/   规则/、术语表.md、禁忌.md、待解决问题.md
  文风/     文风规范.md（可测口径＋长短交错＋情绪两层）、人物口吻.md
  正文/     未切稿.txt     连续文本，不按章分文件
  _检索/    作者决定.md、待办队列.md
```

## 脚本

```bash
node scripts/viz.mjs <项目目录> [--open]   # 渲染骨架总览.html（点块打开 md）
node scripts/init-project.mjs <项目目录>    # 建一个空项目骨架
```

渲染器只读，事实以文件为准；改内容永远改 md，不改图。
