# 场景模块

> 「场景」指的是**地点**，不是一场戏。
> 一场戏是骨架块要写的事；这个地方本身才是本模块管的。

## 一、文件结构

```text
场景/
  地点索引.md
  城郊废楼.md
  码头仓库.md
```

## 二、一个地点要写清什么

| 字段 | 说明 |
| --- | --- |
| 名称 | 定名后不再改；简称也登记 |
| 诞生原因 | **这里常常藏着线索或内容**——这地方为什么会是现在这样 |
| 位置 | 在世界里的哪儿，怎么去，隔多远 |
| 形态 | 大致长什么样。必要时上建模式的表述（层数、走向、房间数、边界） |
| 首次出现 | 哪个块第一次到这儿 |
| 常驻的人 | 谁在这儿，谁不能来 |
| 能承载什么戏 | 允许发生什么、不允许发生什么 |

「形态」一栏允许写细，因为迷宫／异空间这类地点，**空间本身就是剧情**。

## 三、接口

- 骨架延伸时到新地点 → 进**待建场景队列**，排队立卡
- 地点卡里若生出线索 → 直接进线索模块
- 检查器查：地点卡与骨架块里的描述是否打架（层数、方位、能进不能进）
