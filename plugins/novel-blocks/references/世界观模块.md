# 世界观模块

> 一切故事的容器。规则一旦定死，检查器拿它当硬约束。

## 一、放什么

```text
世界观/
  世界观索引.md
  规则/           世界的硬规则（什么能做到、什么不能）
  术语表.md       唯一命名来源。正文与骨架出现冲突写法，一律回改
  组织与势力.md
  官方口径.md     台面上怎么说（如「禁止谈论灵异事件」）
  禁忌.md         作者不能碰的线
  待解决问题.md   悬而未决的条目，解决一条划一条
```

## 二、两条硬规矩

1. **术语以术语表为唯一准**。正式名、俗称、别名各归各位，不保留两种并存写法。
2. **禁忌条目未经作者确认，不许当默认规矩使用**。

## 三、纪年法（骨架的时间靠它）

骨架块上挂的绝对时间，用的就是这里定的纪年法。必须写清：

- 纪年名（如「新历」「事故后第三年」）
- 元年是什么事
- 一年分几段（月／季／轮）
- 现在大致处在哪里

定完不随意改。要改，回这里正式修订，并检查已排的骨架块要不要跟着走。

## 四、接口

- 检查器读规则＋术语表＋禁忌，逐块判「这个世界支不支持这么写」
- 骨架里出现新规则 → 先回世界观模块登记，再继续写
