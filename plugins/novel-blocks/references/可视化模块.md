# 可视化模块

> 渲染出来之后，点击对应模块可以直接打开 md 编辑。
> **图不是事实的来源，文件才是。**

## 一、原则

- 图**从文件渲染**，不自己存一份数据，也不新增事实
- 编辑在图外发生：点块 → 打开对应的 `.md` → 改完存盘 → 图重渲染
- 可点的东西有三处：**骨架块**、**线索弧线中点的小方块**、侧栏里的线索与角色
- 因此不存在「图与文件谁为准」的冲突

## 二、主视图：行＝线，横轴两选一

**行是线**（谁的眼睛）。块在哪一行，就说明那一块用谁的视角写——
换线就是**块真的挪到了另一行**，不是加个注。

横轴有两根，切换着看：

| 视图 | 横轴 | 看什么 |
| --- | --- | --- |
| 按写作顺序 | B 编号从左到右，等距 | 顺序本身；换线＝跳行 |
| 按故事时间 | 时间位（数字）从左到右 | **回到过去的块真的往左挪** |

两种视图里，连线都按写作顺序走，带箭头；紫线是回到过去。
同一时刻的块在行内往下叠，表示它们是同一个时间点上的事。

必须画出来的东西：

| 元素 | 怎么画 |
| --- | --- |
| 块 | 左上角是 B 编号；左侧色条按线着色 |
| 绝对时间 | 写在块的第三行 |
| 换线 | 连线上注 `换线 → L2 队长` |
| 时间跳跃 | 连线上注 `相对时间 +91日` |
| 回到过去 | 连线标紫，注 `↩ 回到过去` |
| 线索 | 走上方弧线，从入块连到出块；**中点挂一个可点的小方块** |
| 无出口的线索 | 红框加断线，一眼看到断在哪 |
| 远端孤立块 | 虚线边框 |
| 不可逆块 | 红框 |
| 写作位置 | 游标 |
| 块宽 | ∝ 预估字数，就是节奏 |
| 问题与待办 | 右侧栏，带状态 |

这张图最有用的一点恰好是线索：**哪条线只画出去、没画回来，一眼看得见。**

## 三、其他视图

- **角色视图**：卡片式，右侧挂认知边界；变更链画成属性随块变化的折线
- **线索总览**：每行一条，入出连线加状态
- **关系视图**：两人之间画双向箭头，两边标签各写各的，不一致时高亮
- **地点视图**：关系网形式，标出人物在各地点的分布

## 四、已经落地的渲染器

`_工具/骨架可视化/viz.mjs`（Node，零依赖）已经能读这套结构并出图：

```bash
node _工具/骨架可视化/viz.mjs <项目目录> [--open]
```

用法与文件格式见 `_工具/骨架可视化/README.md`。

旧的 `novel-viz` 是 JSON 主存＋md 导出，与本模块「文件即事实」的前提冲突，
不复用它的数据层；渲染思路可以参考。
