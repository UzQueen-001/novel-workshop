# 文风与口吻

> 这一份是从一次真实的失败里长出来的：一轮写了三万字，被作者当场指出
> 「平、短、到处句号、千人一面」。实测数据：叙述句均长 13.5（作者原稿 29.3）、
> 标准差 6.0（原稿 23.4）、问号 2.6/千字（原稿 3.6）、感叹号 **0**。

## 零、顺序不能反

**先定这一块里谁在什么情绪 → 让句法和标点从那个情绪里长出来 → 最后才事后自查。**

指标表是**警报器，不是方向盘**。查出来不达标，回去找情绪和场景的问题，
**不许直接往句子里塞标点**。

反面例子：一个人听见对方说「我多大了，不知道」，他的第一反应是**困惑**，不是惊叹。
写成「不知道？！」，那是为了凑感叹号。正确的写法是让他把手里的活停下来，
把那两个字再说一遍——一个标点都不加，也比原来活。

## 一、可测口径

**两类场景两套口径**，别压成一套。压成一套的结果就是叙述段和对话段一个样。

| 指标 | 叙述为主的段 | 对白为主的段 |
| --- | --- | --- |
| 叙述句均长 | **26–32 字** | 10–16（叙述句本来就少） |
| 叙述句标准差 | **≥ 18** | 不适用 |
| 叙述句 ≤10 字占比 | ≤ 20% | 不适用 |
| 最长叙述句 | ≥ 60 字 | — |
| 问号 每千字 | 0–2 | **8–12** |
| 感叹号 每千字 | 3–8 | 3–8 |
| 省略号 每千字 | 1–3 | 1–5 |

统计口径：去掉空白 → 按 `。！？…` 切句 → **排除含「」的句子**之后算叙述句。

单独盯一个数字没用。**标准差才是"平"的照妖镜**：均长再长，句句一样长，读着还是机器。

## 二、长短交错

- 一段里至少有一句 **25 字以上**的叙述句，除非这一段全是对白。
- **连续三句都 ≤10 字 = 失败。**要拆，也要先连。
- 长句用逗号、分号、破折号拖长，**不许靠堆形容词**。
- 句子长在哪儿：**动作链、场景细节、旁人的小动作**。这三样是拉长句子的正道。
- 关键动作可以单独成句（「走！」），一段里最多一次。

## 三、情绪要分两层

**第一层挂在骨架上**：每一块有「情绪」（紧张／平缓／悲伤／快乐）与「强度」1–5，
这是这场戏的温度。写之前先看这一格。

**第二层挂在角色上**：每个角色一份**状态曲线**，按拐点记他此刻是什么状态。
它和角色的「认知边界」是一对——**认知边界管他知道什么，状态曲线管他此刻是什么状态。**
只记拐点，不记流水。

情绪落到句法上：

| 情绪 | 这么写 |
| --- | --- |
| 紧张 | 长句挤压（一句里塞满动作）＋ 突然一个短句断掉 |
| 平缓 | 可以短，但要掺长句；写物、写光、写声音 |
| 悲伤 | 放慢，用省略号与重复；句子反而变长，拖 |
| 快乐／热闹 | 感叹号、口语词、成串的短句，节奏加快 |

## 四、口吻卡（千人一面的解药）

**每个有名字的角色一份口吻卡**，写他的对白之前先读。**没有卡的角色一律当无名角色**：
不给名字、不给口癖、不给第二场戏。

三条硬规矩：

1. 不同角色的口头禅不许撞车；
2. 不许让每个人都用问句——**有人从来不问**；
3. 不许让每个人的回答都一样长。

### 凶不靠字少，靠反问

一个人凶，不是把句子砍到三个字就完事。他可以用**反问制造质疑感**：
「怎么，我说错了？」「谁跟你说的？」「你问这个干什么。」

### 自信不只一种写法

只写「直勾勾盯着对方」最没劲。还有更活的一种——**轻浮的自信**：
把话让给对方，再拿话把对方堵回去。「怎么？你不信？你自己去看。」
他不是不在乎，他是懒得解释。

### 同一种句式，三种心思

| 人设 | 反问是干什么的 | 例子 |
| --- | --- | --- |
| 带队的老手 | 质疑、压人 | 「我不说第二遍。怎么，你要试试？」 |
| 街坊老人 | 家常、反将一军 | 「关了？不是一直开着的吗。」 |
| 油滑的旧人 | 推诿、带刺 | 「你都不知道上面是谁，你还敢问？」 |

句式可以共用，**心思不能共用**——心思一共用，人就成了一张脸。

## 五、字数预估必须核对

骨架每块的「预估」不是装饰。**一块写完当场核一次**：
实际字数落在预估的 **0.8–1.2 倍**之间才算过；低于 0.8，回去补**场景细节**，不是补形容词。

上一轮的教训：骨架每块估 640 字，实际写了 320 字，一路没核，
结果三万的骨架只产出不到两万字。

## 六、仍然禁止的

- 设定不写实，来源不点明，不解释、不总结。
- 不写主角心理独白；情绪靠动作与场面留白。
- 不用文艺腔比喻（仿佛／宛如／如同），不堆成语。
