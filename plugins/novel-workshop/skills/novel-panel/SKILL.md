# 评审团编制

一个角色只干一件事。派工时照这张表点人，不要让一个 agent 兼两职——职责一重叠，互盲就破了。

## 编排者（主 agent）

唯一能改骨架、改台账、改规划的角色；回炉决定、退回哪一步，由它裁决；评分汇总、缝合、终稿也归它。**不参与打分，也不参与判定。**

## 角色表

| 角色 | 数量 | 技能 | 输入 | 输出 | 明令禁止 |
| --- | --- | --- | --- | --- | --- |
| 拆解 agent | 每份成品 1 名 | `novel-dissect` | 成品正文＋它的骨架 | 骨架／软骨／血肉三份清单 | 改一个字；评价好坏 |
| 判定 agent | 11 名，一人一特征 | `novel-ai-judge` | 正文＋自己那张特征卡＋反向表＋文风样本 | 命中清单（位置、片段、标记、确信度） | 改写任何字；报告别的特征 |
| 改写 agent | 与命中的特征数相同 | `novel-deai` | 正文＋对应特征卡＋命中清单 | 改好的全文 | 自己判断新命中；改清单外的字 |
| 评审 agent | 每维度 2 名，共 16 名 | `novel-vote` | 打乱顺序、去掉来源标识的候选段 | 该维度的分数与理由 | 看别人的分；猜候选来自哪条线 |
| 校准 agent | 每轮 1 名 | `novel-calibrate` | 成品＋骨架＋禁忌清单 | 越界与禁忌报告 | 顺手改写已通过的部分 |
| 逻辑审查 agent | 每轮 1 名 | `novel-logic` | 成品＋台账＋前文 | 分级报告 | 润色文字 |

预算紧的时候可以减人，但要在评分台账里注明减到了几个：评审 agent 最少每维度 1 名；判定 agent 可以只跑风险高的那几个特征，其余标注「本轮未判」。

## 互盲规则

- **判定 agent 之间互不看** —— 11 名各写各的清单，汇总之前不交流；
- **判定与改写分开** —— 判的人不写，写的人不判；
- **评审 agent 不知道来源** —— 候选顺序打乱、去掉来源标识，它不知道自己在评线1还是线2；
- **收齐前互不公开** —— 分数与评语统一交回编排者，全部收齐之后才算平均。

## 谁不能兼任谁

- 同一个特征，判定 agent 与改写 agent 不能是同一名；
- 生成 agent（升维线、降维线）不能兼任评审 agent；
- 拆解 agent 不能兼任评审 agent，也不能兼任改写 agent。
