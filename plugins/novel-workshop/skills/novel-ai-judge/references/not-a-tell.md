# 不作为 AI 痕迹的清单

来源：公开语料研究项目 lieflat-less-ai-tone（作者 larashero3-dotcom，MIT License，Copyright (c) 2026 shiujan）。该项目用 5 个模型 300 篇 AI 文本（117.9 万汉字）对照 329 篇人类文章（164.8 万汉字）逐条实测，下表是**被实测推翻、不许据此报命中**的特征。

| 特征 | 为什么不报 |
| --- | --- |
| 句长、段落长度不够参差 | 与人类写作无差别。不要为制造节奏调句长或拆段 |
| 单字虚词偏少（就／很／了） | 方向是补不是删，补虚词无法验收 |
| 反复写全称、少用代词 | 实测人类比 AI 更常重复同一名词 |
| 被动句 | 抽象被动远低于收录门槛 |
| 名词化、长句本身 | 现代汉语书面语的正常写法 |
| 正文里的「首先……其次……最后」 | 与人类写作无差别。特征 06 只管小标题编号 |
| 句内同构排比 | 人类用得不比 AI 少。特征 03 只处理句间重复 |
| 问句、设问、问句小标题 | 正文问句人类远多于 AI，删掉更不像人写 |
| 比喻本身、比喻独立成段 | 人类用得比 AI 多。特征 07 只处理理想化职业人格喻体 |
| 「以一种……的方式」「扮演……角色」「使得……能够」 | 实测全部低于收录门槛 |

判定 agent 和改写 agent 都要读这一份。它和特征卡同等效力：**特征卡没写、这张表没排除，也不许报。**
