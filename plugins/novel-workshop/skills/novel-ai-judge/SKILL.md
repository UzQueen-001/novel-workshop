# AI 痕迹判定

只判，不改。改动由改写 agent 按你的清单执行。

## 一次只认一个特征

派工时给每名 agent **一个**特征编号，它只查这一条。特征卡在 `references/features/` 下，共十一张：

| 编号 | 特征 |
| --- | --- |
| 01 | 翻案腔 |
| 02 | 顿号密集罗列 |
| 03 | 句间同构与平级凑数 |
| 04 | 破折号滥用 |
| 05 | 冒号滥用 |
| 06 | 序数词当小标题 |
| 07 | 拟人化喻体 |
| 08 | 把已有的具体数据写回概括表述 |
| 09 | 禁用起手式 |
| 10 | 翻译腔（五种） |
| 11 | 段首零主语评论 |

每个 agent 开工前读三份东西：自己那张特征卡、`references/not-a-tell.md`、`05_文风/文风样本.txt`。**不要读别的特征卡**——读多了就会越界发问，把不属于自己的问题也报上来。

## 判定流程

1. 逐句扫一遍，只找自己特征卡上列出的触发标记；
2. 命中就记一条：段号、原句片段、触发标记、确信度（高／中／低）；
3. 拿不准的写「存疑」，附上拿不准的原因，**不要给结论**；
4. 只报自己这一条，不评论别的特征，也不提改法建议。

## 反向约束

`references/not-a-tell.md` 里那张表是硬约束：表上列的特征看着像 AI 味，实测站不住，**不许据此报命中**。句长不参差、被动句、名词化、句内排比、比喻本身、正文里的「首先……其次」——全都不是。

## 文风优先

作者自己的写法和特征卡冲突时，以 `05_文风/文风样本.txt` 为准。他本来就爱用破折号，那一处就不是痕迹。

## 交回来的格式

```text
特征 04 · 破折号滥用
命中 3 处

1. 第 12 段｜「答案其实很简单——专注」｜标记：揭晓式破折号｜确信度：高
2. 第 27 段｜「他找到了一条路——一条所有人都忽略的路」｜标记：同上｜确信度：高
3. 第 41 段｜「凌晨三点——天还没亮」｜标记：插入式补充｜确信度：中｜存疑：可能是作者的时间强调习惯
```

零命中就写「特征 NN · 零命中」，不要凑数，也不要为了有话可说把确信度压低的条目塞进来。
