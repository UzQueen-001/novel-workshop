# 升维生成（拟画图生成法）

## 输入

`04_章节/第NN章/成熟骨架.txt`。没有成熟骨架就先走升维解剖，不要凭印象硬写。

写之前读：`01_世界/`（世界观、总体矛盾）、`02_人物/`（人物卡、角色状态）、`00_台账/`（伏笔账本、待解决问题）、`05_文风/文风样本.txt`。

## 生成方式

这是标准生成流程：**不做事先设计**。不写分镜，不列逐句计划，不把这一章再拆一层规划。骨架已经定了要发生什么，剩下的就是按法则把它写出来。

写法是逐层加维度，像从线稿往上加：

1. 先把每个节点写成事件本身，只保证因果与信息传递成立；
2. 再加空间与时间——人在哪、光是什么样、前后隔多久；
3. 再加人物维度——他要什么、他此刻相信什么、他身体什么状态、他没说出口的是什么；
4. 再加关系维度——对方的反应、两人之间的距离变化；
5. 最后才是语言层面的密度与节奏。

每一层都只加维度，不加内容。越界规则见下节，它是这个工作流的铁律。

## 骨架是硬边界

逐层叠加是允许的，超越骨架是不允许的。加维度加的是同一件事的厚度，不是新的事：

- 不新增事件、回合、转折、巧合；
- 不新增人物、势力、场次、地点；
- 不新增设定、规则、情报、伏笔；
- 不改动事件顺序、因果关系、结果，也不改变人物关系的走向；
- 不把节点写得比它本身更大——节点说「两人谈崩」，就不许写成找到了第三条路。

判断标准很简单：**写完的正文里，去掉所有描写与维度，剩下的骨架必须和原来的骨架一模一样。** 多出来的就是越界。

需要越界时，唯一的合法动作是回到升维解剖补节点，补完再回来写。不许在正文里悄悄扩，也不许写完再回头补骨架。

## 内容法则

以下每一条都是硬约束：

- 世界观规则与代价不许通融，主角也不能例外；
- 人物的底线、欲望、已知与未知严格对齐角色状态，不许为了推进情节让他做出设定里不会做的事；
- 伏笔只埋不解释，该回收的按伏笔账本回收；
- 术语、人名、地名与库里写法完全一致，不出现两种写法并存；
- 文风按 `05_文风/文风样本.txt` 的参数走；
- 全章落在骨架给定的各段目标字数内，总字数 2000–5000。

发现骨架本身与设定冲突时，停下来报告冲突，不要偷偷改设定也不要偷偷改骨架。

## 交付

标准格式落盘：

- 正文写进 `04_章节/第NN章/正文_升维.txt`；
- 首行写章号与章名，正文不分小节标题，不插作者说明；
- 章末附一行统计：总字数、各节点实际字数与目标字数的偏差。

写完走一遍 `novel-deai`；这一章定稿前走一遍 `novel-logic`。
